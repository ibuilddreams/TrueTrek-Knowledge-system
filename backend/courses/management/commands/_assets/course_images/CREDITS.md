# Course catalog photographs

The thumbnail pool `seeddata` attaches to every seeded course, one set per
category in `CATEGORY_NAMES`. `_course_images.py` maps a course onto one of
these by category and position, so adjacent cards in the catalog grid never
show the same photograph.

## Where they come from and what they are licensed under

Every file is **CC0 1.0 (public domain dedication)**, sourced from
[StockSnap.io](https://stocksnap.io) and found through the
[Openverse](https://openverse.org) API with `license=cc0&source=stocksnap`.
CC0 waives all rights: no attribution is required and commercial use is
permitted. The credits below are recorded so the provenance of each file can
be re-checked, not because they are a licence condition.

Each was downscaled to 800x500 (centre crop, JPEG quality 82, progressive)
for the 224px-tall card thumbnail the catalog renders.
